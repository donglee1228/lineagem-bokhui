복희섭 장비보유현황 - 사용법
==============================

웹페이지 주소: https://donglee1228.github.io/bokhui-gear/
고칠 파일은 딱 하나: 장비현황데이터.js

메모장으로 장비현황데이터.js 를 열어 아래처럼 고친 뒤 저장하고
GitHub에 올리면(아래 "올리는 법") 1~2분 뒤 웹페이지에 반영됩니다.


1. 장비 항목 정하기 (표의 칸)
------------------------------
  장비항목: ["장비A", "장비B", "장비C"],

  - 이름은 큰따옴표 " " 로 감싸고, 사이에 쉼표.
  - 적은 순서대로 표의 칸이 왼쪽부터 생깁니다.


2. 특화템 정하기
------------------------------
  특화템: ["특화템A", "특화템B"],


3. 혈원 추가 + 보유 표시
------------------------------
  혈원: [
    { 이름: "혈원1", 클래스: "기사", 보유장비: ["장비A"], 보유특화템: ["특화템A"] },
    { 이름: "혈원2", 클래스: "요정", 보유장비: [], 보유특화템: [] }
  ],

  - 보유장비 / 보유특화템 안에 적은 것 = 보유, 안 적은 것 = 미보유.
  - 이름은 1번, 2번에 적은 이름과 글자(띄어쓰기 포함)가 똑같아야 합니다.
  - 혈원이 여러 명이면 } 뒤에 쉼표(,)를 넣고 다음 줄에 이어서 적습니다.
    (마지막 사람 뒤 쉼표는 있어도 되고 없어도 됩니다)
  - 클래스는 비워도 됩니다: 클래스: ""


4. 공지/글 쓰기
------------------------------
  공지: [
    { 날짜: "2026-11-12", 제목: "공성 일정 안내", 본문: "첫째 줄\n둘째 줄" }
  ],

  - 날짜는 2026-11-12 처럼 적으면 최신 글이 위로 정렬됩니다.
  - 본문에서 줄바꿈은 \n


5. 기타
------------------------------
  혈맹이름: "혈맹명"   → 제목 아래에 "혈맹명 혈맹" 으로 표시
  갱신일: "2026-11-12" → 제목 아래에 "마지막 갱신 2026-11-12" 표시


올리는 법
------------------------------
  방법1) GitHub 웹: https://github.com/donglee1228/bokhui-gear 에서
         장비현황데이터.js 클릭 → 연필(편집) 아이콘 → 고치고 Commit changes.
  방법2) 이 폴더에서 PowerShell:
         git add .
         git commit -m "장비현황 갱신"
         git push


페이지가 갑자기 비어 보이면
------------------------------
  대부분 쉼표나 따옴표 짝이 빠진 경우입니다. 방금 고친 줄을 다시 확인하세요.
